# Docs

- README.md (EN) / README.ja.md (JA): only what Collie is, how to try it, and links. Don't add feature details there.
- Details live in `docs/<topic>.md` + `docs/<topic>.ja.md`. Change both languages together.
- Write only what the code, `collie --help`, `mise tasks` or the UI can't tell you: steps to run, gotchas, and guarantees (security, sharing, billing). No flag tables, file layouts or implementation details.
- A change to user-visible behavior updates the matching doc in the same commit.
