# Security policy

**English** | [日本語](#日本語)

Please don't report vulnerabilities in public issues. Report them privately: **Security** tab → **Report a vulnerability** ([link](https://github.com/tattsun/collie/security/advisories/new)).

Fixes ship in a new release, and servers get them through Admin → **Updates**. Older releases aren't patched.

What Collie protects and what it doesn't: [docs/security.md](docs/security.md).

## 日本語

脆弱性は公開の Issue ではなく、非公開で報告してください。**Security** タブ → **Report a vulnerability**（[リンク](https://github.com/tattsun/collie/security/advisories/new)）から送れます。

修正は新しいリリースとして出し、各サーバは Admin → **Updates** から更新します。古いリリースへの修正は出しません。

Collie が何を守り、何を守らないかは [docs/security.ja.md](docs/security.ja.md) にあります。
